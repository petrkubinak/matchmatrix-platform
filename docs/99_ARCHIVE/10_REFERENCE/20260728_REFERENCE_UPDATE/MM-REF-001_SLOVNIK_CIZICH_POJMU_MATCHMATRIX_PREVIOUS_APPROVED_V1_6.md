# 1. Účel

MM-REF-001 je stručný překladový slovník cizích a technických výrazů používaných v projektu MatchMatrix.

Dokument obsahuje pouze:

- cizí nebo technický výraz,
- jeho doporučený český překlad.

Podrobné definice, zdrojové dokumenty, cílové kapitoly a klikací navigace jsou vedeny v `MM-REF-002`.

Verze 1.7:

- zachovává všech 228 schválených pojmů verze 1.6,
- doplňuje 35 nových pojmů z aktualizovaných dokumentů MM-DOC-000, MM-DOC-200, MM-DOC-300, MM-DOC-800 a MM-DOC-900,
- doplňuje názvosloví ze standardů MM-STD-003, MM-STD-004 a MM-STD-007,
- zpřesňuje terminologii aktivních dokumentů, archivace, ověřování, Git stavu, providerových identit a provozu PC1 / PC2,
- nevkládá duplicitní pojmy.

- České popisky uživatelského rozhraní používají překlady z tohoto dokumentu.
