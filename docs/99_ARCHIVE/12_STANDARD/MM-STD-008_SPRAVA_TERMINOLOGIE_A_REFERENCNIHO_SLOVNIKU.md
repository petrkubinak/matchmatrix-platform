# MM-STD-008

# SPRÁVA TERMINOLOGIE A REFERENČNÍHO SLOVNÍKU

Verze: **1.0** | Stav: **REVIEW**

## Principy

- Jeden pojem = jedna referenční definice.
- Referenčním dokumentem je MM-REF-001.
- Nový pojem se vysvětlí při prvním použití.
- Po schválení se zapíše do MM-REF-001.
- Zastaralé pojmy se označí jako DEPRECATED.

## Životní cyklus

Vznik → Návrh → Review → Schválení → Zápis do MM-REF-001 → Aktivní používání → Archivace.

## Documentation Management System

Budoucí systém bude automaticky:
- vyhledávat nové pojmy,
- porovnávat je se slovníkem,
- navrhovat nové záznamy,
- upozorňovat na duplicity,
- připravovat novou verzi MM-REF-001.
