# 1. Účel

Tento standard definuje jednotný způsob předávání kontextu mezi dokumentací, členy týmu a systémy umělé inteligence.

Jeho cílem je minimalizovat ztrátu kontextu při přechodu do nového chatu, zapojení nové AI nebo navázání práce po delší době.

# 2. Povinné sekce

- AI CONTEXT
- PROJECT SNAPSHOT
- DATABASE SNAPSHOT
- CURRENT STATUS
- OPEN QUESTIONS
- NEXT STEP

# 3. Automatická aktualizace

Budoucí Documentation Management System bude automaticky aktualizovat PROJECT SNAPSHOT, DATABASE SNAPSHOT a CURRENT STATUS.

# 4. Přínosy

- rychlé navázání práce
- omezení duplicitních návrhů
- jednotný kontext pro AI
- přesnější návrhy
